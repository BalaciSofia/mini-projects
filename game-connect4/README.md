# Connect 4

A Python implementation of Connect 4 with both a Pygame graphical interface and a console-based interface. The game allows a human player to compete against the computer, using the same core game logic in both versions.

## Features

- Human vs computer gameplay  
- Graphical interface using Pygame  
- Console-based version  
- Win detection (horizontal, vertical, diagonal)  
- Simple AI (winning + blocking strategy)  
- Unit tests across all application layers  

## Run

From the `game-connect4` folder:

```
pip install pygame
python -m start.start
```
