# Order and Chaos

A console version of the Order and Chaos board game on a 6x6 grid. You play Order and try to get 5 identical symbols (X or O) in a row; the computer plays Chaos and tries to block you. Every move is saved to `save.txt`, so a game can be resumed with "Load game".

## Run

```
pip install texttable faker
python start.py
```
